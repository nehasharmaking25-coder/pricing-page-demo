# World-Class Portfolio — Build Plan

**Owner:** Neha Sharma — Designer / Developer
**Stack:** Next.js (App Router) + TypeScript + Tailwind CSS + Framer Motion + GSAP (ScrollTrigger) + Lenis
**Theme:** Light + Dark mode with toggle

## Steps

1. **Scaffold** — Set up Next.js App Router project with TypeScript and Tailwind CSS.
2. **Animation core** — Install and wire Framer Motion, GSAP + ScrollTrigger, and Lenis smooth scrolling.
3. **Theme system** — Light/dark mode with a toggle, persisted to localStorage, no flash on load.
4. **Hero** — Bold headline, role, CTA buttons, animated intro and background.
5. **About** — Bio, photo placeholder, quick facts, scroll-reveal.
6. **Projects** — Grid of project cards with hover micro-interactions and links.
7. **Skills** — Skills grouped by category with animated bars/tags.
8. **Contact** — Contact form + social links (GitHub, LinkedIn, email).
9. **Polish & test** — Responsive layout, reduced-motion support, production build check.

## Notes
- Content (bio, projects, skills, links) starts as tasteful placeholders; Neha will send real info to swap in.
- The existing `index.html` (pricing page) will be replaced by the Next.js app.
